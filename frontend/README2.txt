تغییرات اعمال‌شده در این سه فایل:

1) js/admin-categories.js
2) js/admin-products.js
3) js/admin-reviews.js

تغییر ۱: آدرس API از مسیر نسبی (/api/...) به آدرس کامل بک‌اند تغییر کرد:
    http://127.0.0.1:8787/api/...
دلیل: با مسیر نسبی، درخواست به سرور فعلی صفحه (Live Server روی پورت 5500)
می‌رفت، نه به بک‌اند روی پورت 8787. برای همین 404 می‌گرفتی و چون Live
Server به‌جای JSON یه صفحه HTML برمی‌گردوند، ارور
"Unexpected token '<', <!DOCTYPE" هم می‌گرفتی.

تغییر ۲: همه‌ی credentials: "same-origin" به credentials: "include" تغییر
کرد (همون دلیل قبلی - دو پورت متفاوت = دو origin متفاوت).

تغییر ۳: مسیرهای ریدایرکت به /admin-login.html نسبی شدن (admin-login.html).

⚠️ نکته مهم درباره‌ی admin-products.js:
توی این فایل عمداً "PRODUCT_CATEGORY_API_URL" دوباره تعریف نشده، چون
admin-categories.js (که قبل از admin-products.js لود میشه) همین اسم رو
از قبل تعریف کرده. توی مرورگر، متغیرهای const/let که توی تگ‌های <script>
جدا نوشته میشن، هرکدوم اگه اسم یکسان داشته باشن با هم تداخل پیدا می‌کنن
و ارور "Identifier has already been declared" میدن که کل اون اسکریپت
اجرا نمیشه. پس این وابستگی بین دو فایل (products به categories) عمدیه؛
اگه بخوای این دو فایل رو کاملاً مستقل از هم کنی، باید اسم متغیر رو توی
یکی از دو فایل عوض کنی.

⚠️ نکته مهم درباره‌ی admin-reviews.js:
مسیر API این فایل با بقیه فرق داره:
    /api/frontend/admin/reviews   (به‌جای /api/admin/reviews)
این دقیقاً همون چیزیه که توی نسخه قبلی فایل بود، پس دست‌نخورده نگهش
داشتم. ولی اگه بک‌اندت همچین روتی نداره (و به‌جاش /api/admin/reviews
داره)، بازم بعد از این فیکس 404 می‌گیری و باید خودت این مسیر رو با روت
واقعی سرورت مطابقت بدی.
